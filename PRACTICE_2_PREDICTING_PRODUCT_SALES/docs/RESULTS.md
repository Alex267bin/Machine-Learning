# Kết quả — Lab 2

Kết quả chưa được điền trước. Chạy pipeline trên dataset thật để sinh:
- `outputs/metrics.json`: schema dữ liệu, số dòng, mốc chia thời gian, tham số tune và metrics.
- `outputs/model_comparison.csv`: bảng so sánh baseline và Random Forest tuned.
- `outputs/test_predictions.csv`: giá trị thật, dự báo và residual trên holdout.
- `outputs/figures/`: actual-vs-predicted, residual plot, so sánh RMSE, feature importance nếu mô hình hỗ trợ.
- `models/best_model.joblib`: pipeline đã fit.

Không sao chép số liệu từ repository tham khảo vào báo cáo này vì dataset, cách xử lý và cách chia tập có thể khác.
