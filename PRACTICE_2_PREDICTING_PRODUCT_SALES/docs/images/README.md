# Biểu đồ được tạo từ quá trình chạy

Quá trình huấn luyện tạo các biểu đồ chẩn đoán mô hình trong `outputs/figures/`. Khi chuẩn bị báo cáo, chỉ sao chép hoặc liên kết những biểu đồ được tạo từ lần chạy đã kiểm tra. Không đưa biểu đồ giả hoặc hình minh họa thay thế vào kho mã nguồn.

Các biểu đồ dự kiến gồm: giá trị thực tế so với dự đoán, phần dư, so sánh hiệu năng mô hình và độ quan trọng đặc trưng nếu mô hình cây được chọn hỗ trợ.
